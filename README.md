# Пригоди на замовлення — перший технічний контур

Працює вже зараз:

- сайт з описом пригоди
- видача іменного квитка після оплати (поки вручну)
- Telegram-бот відкриває кроки тільки з квитком
- локація надсилається **один раз на старті**
- сервер підбирає лавку, воду й кафе
- бот веде «М’яке повернення» по кроках

Оплата LiqPay і Mini App — наступне коло. Не зараз.

## Що натиснути вам (без програмування)

### 1. Створити бота
1. У Telegram відкрийте `@BotFather`
2. Команда `/newbot`
3. Ім’я: наприклад `М’яке повернення`
4. Username: наприклад `myake_povernennya_bot`
5. BotFather дасть **токен**. Збережіть.

### 2. Запустити код на комп’ютері або на хостингу

На комп’ютері (якщо встановлено Node.js):

```bash
cd adventure-engine
cp .env.example .env
```

Відкрийте файл `.env` і впишіть:

```
BOT_TOKEN=токен_від_BotFather
BOT_USERNAME=myake_povernennya_bot
ADMIN_SECRET=будь-який-довгий-пароль
PUBLIC_URL=http://localhost:3000
```

Потім:

```bash
npm install
npm start
```

Сайт: http://localhost:3000  
Адмінка квитків: http://localhost:3000/issue.html

Щоб бот відповідав з вашого ноутбука, ноутбук має бути увімкнений. Для постійної роботи потрібен хостинг (Railway або Render): завантажуєте цю папку, додаєте ті самі змінні середовища, тиснете Deploy.

### 3. Видати доступ людині
1. Вона платить вам як зручно (карта, переказ).
2. Ви відкриваєте `/issue.html`, вводите секрет, отримуєте посилання.
3. Надсилаєте їй тільки це посилання:
   `https://t.me/your_bot?start=t_ab12cd`
4. Вона натискає Start. Квиток прив’язується до її Telegram. Переслати іншому вже не можна.

### 4. Як іде пригода
1. Бот просить гео **один раз**.
2. Сервер шукає місця через OpenStreetMap (без Google-рахунку).
3. Далі кроки текстом. На лавці й у кафе буде кнопка «відкрити шлях».
4. Після фіналу квиток згорає.

## Що де лежить

| Файл | Навіщо |
|---|---|
| `adventures/soft-return.json` | Текст кроків. Правите слова тут |
| `src/bot.js` | Поведінка бота |
| `src/places.js` | Пошук лавки / води / кафе |
| `src/tickets.js` | Квитки |
| `public/index.html` | Вітрина |
| `public/issue.html` | Видача доступу |
| `data/store.json` | З’явиться сама: квитки й сеанси |
